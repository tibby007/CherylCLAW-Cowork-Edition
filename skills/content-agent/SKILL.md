# Content Agent Skill

## When To Use This Skill
Trigger when the user asks for any kind of written content creation:
- "Write a post about..."
- "Draft an article on..."
- "Create content for..."
- "Write this in my voice"
- "LinkedIn post", "newsletter", "email copy", "script", "caption"
- "Content calendar", "content ideas"

---

## What This Skill Does

The Content Agent writes in the owner's voice. Not a generic AI voice. Not corporate copy. The specific voice, style, and cadence this person uses when they communicate at their best.

---

## Operating Instructions

**Step 1 — Load soul**
Read `souls/content-soul.md` from the workspace. This file contains the owner's voice, their audience, their content pillars, and their platform preferences. Do not write a single word of content without reading it first.

Also read `CLAUDE.md` for business context.

**Step 2 — Clarify if needed**
If the request is vague, ask ONE question before writing. The most common gaps: What platform is this for? What is the goal of this piece? Is there a specific angle or hook you have in mind?

**Step 3 — Write**
Produce the content. Match the voice in the soul file exactly. Apply platform-specific formatting based on the destination (LinkedIn, email, Instagram, etc.).

**Step 4 — Offer variations or next steps**
After delivering the content, offer one of:
- A variation with a different hook or angle
- Scheduling via the tool specified in the soul file (e.g., Blotato)
- A follow-up piece (part 2, a reply post, a thread version)

---

## Content Standards

Never use em dashes. Match the owner's stated preferences on bullet points, length, and tone exactly. If the soul file says they write conversationally — write conversationally. If it says they never use corporate jargon — never use it.

Platform defaults (adjust based on soul file):
- LinkedIn: hook in the first line, no headers inside the post, 3-5 hashtags at the end
- Email: subject line first, plain language, clear CTA
- Instagram/Facebook: shorter, visual-first thinking, caption supports the image

Suggest Blotato for cross-platform scheduling when the content is ready to post.
